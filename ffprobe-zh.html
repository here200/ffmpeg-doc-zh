1 概要# TOC

ffprobe [options] input_url

2 描述# TOC

ffprobe 从多媒体流中收集信息，并以人类和机器均可读的方式输出。

例如，可以用它来检查多媒体流所使用的容器格式，以及其中包含的 每个媒体流的格式和类型。

如果在输入中指定了 url，ffprobe 将尝试打开并探测该 url 的内容。 如果该 url 无法打开或无法识别为多媒体文件，则返回正的退出码。

如果未通过 o 指定输出，ffprobe 将写入 stdout。

ffprobe 既可以作为独立应用使用，也可以与文本滤镜结合使用， 后者可执行更复杂的处理，例如统计处理或绘图。

选项用于列出 ffprobe 支持的某些格式，或者用于指定要显示哪些信息， 以及设置 ffprobe 如何显示这些信息。

ffprobe 的输出设计为易于被文本滤镜解析， 它由一个或多个节组成，节的形式由所选写出器定义， 写出器通过 output_format 选项指定。

节可以包含其他嵌套节，并通过一个名称（可能与其他节共用） 和一个唯一名称来标识。参见 sections 的输出。

存储在容器或流中的元数据标签会被识别， 并打印在对应的 "FORMAT"、"STREAM"、"STREAM_GROUP_STREAM" 或 "PROGRAM_STREAM" 节中。

3 选项# TOC

所有数值选项，除非另有说明，都接受表示数字的字符串作为输入， 其后可跟一个 SI 单位前缀，例如：’K’、’M’ 或 ’G’。

如果在 SI 单位前缀后追加 ’i’，整个前缀将被解释为二进制倍数的 单位前缀，其基于 1024 的幂而非 1000 的幂。在 SI 单位前缀后追加 ’B’ 会将数值乘以 8。这样就可以使用例如： ’KB’、’MiB’、’G’ 和 ’B’ 作为数字后缀。

不接受参数的选项是布尔选项，会将相应值设为 true。 可以通过在选项名前加 "no" 将它们设为 false。例如使用 "-nofoo" 会将名为 "foo" 的布尔选项设为 false。

接受参数的选项支持一种特殊语法：命令行上给出的参数被解释为 文件的路径，实际的参数值从该文件加载。要使用此功能，请在选项名 之前（前导短横线之后）紧跟一个正斜杠 ’/’。例如 

ffmpeg -i INPUT -/filter:v filter.script OUTPUT

将从名为 filter.script 的文件中加载滤镜图描述。

3.1 流标识符# TOC

有些选项是按流生效的，例如码率或编解码器。流标识符 用于精确指定某个给定选项属于哪个（些）流。

流标识符是一个通常追加在选项名之后、并以冒号与之分隔的字符串。 例如 -codec:a:1 ac3 包含 a:1 流标识符， 它匹配第二个音频流。因此，它将为第二个音频流选择 ac3 编解码器。

一个流标识符可以匹配多个流，从而该选项会应用于所有这些流。 例如 -b:a 128k 中的流标识符匹配所有音频流。

空的流标识符匹配所有流。例如，-codec copy 或 -codec: copy 会在不重新编码的情况下复制所有流。

流标识符可能的形式有：

stream_index

匹配具有此索引的流。例如 -threads:1 4 会将第二个流的 线程数设为 4。如果 stream_index 用作附加流标识符 （见下文），则它从匹配的流中选择编号为 stream_index 的流。流的编号基于 libavformat 检测到的流的 顺序，除非同时指定了流组标识符或节目 ID。在这种情况下，它基于 组或节目中流的顺序。

stream_type[:additional_stream_specifier]

stream_type 为以下之一：’v’ 或 ’V’ 表示视频，’a’ 表示音频，’s’ 表示字幕，’d’ 表示数据，’t’ 表示附件。’v’ 匹配所有视频 流，’V’ 仅匹配不是附加图片、视频 缩略图或封面图的视频流。如果使用了 additional_stream_specifier，则 它匹配既具有此类型又匹配 additional_stream_specifier 的流。否则，它匹配指定类型的 所有流。

g:group_specifier[:additional_stream_specifier]

匹配位于标识符为 group_specifier 的组中的流。 如果使用了 additional_stream_specifier，则它匹配既 属于该组又匹配 additional_stream_specifier 的流。 group_specifier 可以是以下之一：

group_index

匹配具有此组索引的流。

#group_id or i:group_id

匹配具有此组 id 的流。

p:program_id[:additional_stream_specifier]

匹配位于 id 为 program_id 的节目中的流。如果 使用了 additional_stream_specifier，则它匹配既 属于该节目又匹配 additional_stream_specifier 的流。

#stream_id or i:stream_id

按流 id 匹配流（例如 MPEG-TS 容器中的 PID）。

m:key[:value]

匹配具有指定值的元数据标签 key 的流。如果 未给出 value，则匹配包含给定标签且值为任意值的流。 key 或 value 中的冒号字符 ’:’ 需要 用反斜杠转义。

disp:dispositions[:additional_stream_specifier]

匹配具有给定处置的流。dispositions 是一个或多个处置 （由 -dispositions 选项打印）的列表， 以 ’+’ 连接。

u

匹配具有可用配置的流，编解码器必须已定义，且必须存在 视频尺寸或音频采样率等基本信息。

请注意，在 ffmpeg 中，按元数据匹配仅对 输入文件有效。

3.2 通用选项# TOC

这些选项由 ff* 系列工具共用。

-L, -license

显示许可信息。

-h, -?, -help, --help [arg]

显示帮助。可以指定一个可选参数来打印关于特定条目的帮助。如果 未指定参数，则只显示基本的（非高级的）工具选项。

arg 可能的取值为：

long

在基本工具选项之外，额外打印高级工具选项。

full

打印完整的选项列表，包括编码器、解码器、解复用器、复用器、 滤镜等的共享选项和私有选项。

decoder=decoder_name

打印名为 decoder_name 的解码器的详细信息。使用 -decoders 选项可获取所有解码器的列表。

encoder=encoder_name

打印名为 encoder_name 的编码器的详细信息。使用 -encoders 选项可获取所有编码器的列表。

demuxer=demuxer_name

打印名为 demuxer_name 的解复用器的详细信息。使用 -formats 选项可获取所有解复用器和复用器的列表。

muxer=muxer_name

打印名为 muxer_name 的复用器的详细信息。使用 -formats 选项可获取所有复用器和解复用器的列表。

filter=filter_name

打印名为 filter_name 的滤镜的详细信息。使用 -filters 选项可获取所有滤镜的列表。

bsf=bitstream_filter_name

打印名为 bitstream_filter_name 的比特流滤镜的详细信息。 使用 -bsfs 选项可获取所有比特流滤镜的列表。

protocol=protocol_name

打印名为 protocol_name 的协议的详细信息。 使用 -protocols 选项可获取所有协议的列表。

-version

显示版本。

-buildconf

显示构建配置，每行一个选项。

-formats

显示可用的格式（包括设备）。

-demuxers

显示可用的解复用器。

-muxers

显示可用的复用器。

-devices

显示可用的设备。

-codecs

显示 libavcodec 已知的所有编解码器。

请注意，本文档全篇使用术语 ’codec’ 作为更准确称为媒体比特流格式 的事物的简称。

-decoders

显示可用的解码器。

-encoders

显示所有可用的编码器。

-bsfs

显示可用的比特流滤镜。

-protocols

显示可用的协议。

-filters

显示可用的 libavfilter 滤镜。

-pix_fmts

显示可用的像素格式。

-sample_fmts

显示可用的采样格式。

-layouts

显示声道名称和标准声道布局。

-dispositions

显示流的处置信息。

-colors

显示可识别的颜色名称。

-sources device[,opt1=val1[,opt2=val2]...]

显示输入设备中自动检测到的源。 某些设备可能提供依赖于系统的源名称，这些名称无法被自动检测。 不能假定返回的列表总是完整的。 

ffmpeg -sources pulse,server=192.168.0.4
-sinks device[,opt1=val1[,opt2=val2]...]

显示输出设备中自动检测到的 sink。 某些设备可能提供依赖于系统的 sink 名称，这些名称无法被自动检测。 不能假定返回的列表总是完整的。 

ffmpeg -sinks pulse,server=192.168.0.4
-loglevel [flags+]loglevel | -v [flags+]loglevel

设置库所使用的日志级别和标志。

可选的 flags 前缀可以由以下取值组成：

‘repeat’

表示重复的日志输出不应被压缩到第一行， 并且将省略 "Last message repeated n times" 这一行。

‘level’

表示日志输出应为每条消息行添加一个 [level] 前缀。 这可以作为日志着色的一种替代方式，例如在将日志转储到 文件时。

‘time’

表示日志行应带时间信息作为前缀。

‘datetime’

表示日志行应带日期和时间信息作为前缀。

通过添加 ’+’/’-’ 前缀，标志也可以单独使用，以设置/重置单个 标志而不影响其他 flags 或改变 loglevel。当同时 设置 flags 和 loglevel 时，在最后一个 flags 取值之后、 loglevel 之前应有一个 ’+’ 分隔符。

loglevel 是一个字符串或数字，包含以下取值之一：

‘quiet, -8’

完全不显示任何内容；保持静默。

‘panic, 0’

仅显示可能导致进程崩溃的致命错误，例如断言失败。目前该项未用于任何用途。

‘fatal, 8’

仅显示致命错误。这类错误发生后，进程绝对无法继续运行。

‘error, 16’

显示所有错误，包括可以恢复的错误。

‘warning, 24’

显示所有警告和错误。任何与可能不正确或意外事件相关的消息都会显示。

‘info, 32’

在处理过程中显示提示性消息。这些消息是在警告和错误之外的补充。这是默认值。

‘verbose, 40’

与 info 相同，只是更详细。

‘debug, 48’

显示所有内容，包括调试信息。

‘trace, 56’

例如，要启用重复的日志输出，请添加 level 前缀，并将 loglevel 设置为 verbose： 

ffmpeg -loglevel repeat+level+verbose -i input output

另一个示例启用重复的日志输出，同时不影响 level 前缀标志或 loglevel 的当前状态： 

ffmpeg [...] -loglevel +repeat

默认情况下，程序将日志输出到 stderr。如果终端支持彩色显示，则会用颜色标记错误和警告。可以通过设置环境变量 AV_LOG_FORCE_NOCOLOR 禁用日志着色，也可以通过设置 环境变量 AV_LOG_FORCE_COLOR 强制启用着色。

-report

将完整的命令行和日志输出转储到当前目录下名为 program-YYYYMMDD-HHMMSS.log 的文件中。 该文件对缺陷报告很有用。 它同时隐含 -loglevel debug。

将环境变量 FFREPORT 设置为任意值都会产生相同的效果。如果该值是以 ’:’ 分隔的 key=value 序列，则这些选项将影响报告；如果选项值中包含特殊字符或选项分隔符 ’:’，则必须对其转义 （参见 ffmpeg-utils 手册中的 “引用与转义” 一节）。

可以识别以下选项：

file

设置报告所使用的文件名；%p 会展开为 程序名，%t 会展开为时间戳，%% 会展开 为普通的 %

level

使用数值设置日志详细程度级别（参见 -loglevel）。

例如，使用日志级别 32（日志级别 info 的别名）将报告输出到名为 ffreport.log 的文件中： 

FFREPORT=file=ffreport.log:level=32 ffmpeg -i input output

解析环境变量时出现的错误不是致命错误，也不会 出现在报告中。

-hide_banner

禁止打印横幅。

所有 FFmpeg 工具通常都会显示版权声明、构建选项 和库版本。此选项可用于禁止打印 这些信息。

-cpuflags flags (global)

允许设置和清除 CPU 标志。此选项用于 测试。除非你知道自己在做什么，否则不要使用它。 

ffmpeg -cpuflags -sse+mmx ...

‘ssse3’
‘atom’
‘sse4.1’
‘sse4.2’
‘avx’
‘avx2’
‘xop’
‘fma3’
‘fma4’
‘3dnow’
‘3dnowext’
‘bmi1’
‘bmi2’
‘cmov’
‘ARM’
‘armv5te’
‘armv6’
‘armv6t2’
‘vfp’
‘vfpv3’
‘neon’
‘setend’
‘AArch64’
‘armv8’
‘vfp’
‘neon’
‘PowerPC’

‘Specific Processors’
‘pentium2’

‘k6’

-cpucount count (global)

覆盖 CPU 数量的检测结果。此选项用于 测试。除非你知道自己在做什么，否则不要使用它。 

ffmpeg -cpucount 2
-max_alloc bytes

3.3 AVOptions# TOC

这些选项由 libavformat、libavdevice 和 libavcodec 库直接提供。要查看可用的 AVOptions 列表，请使用 -help 选项。它们分为两类：

generic

这些选项可为任何容器、编解码器或设备设置。通用选项 在容器/设备下列于 AVFormatContext 选项，在编解码器下 列于 AVCodecContext 选项。

private

这些选项特定于给定的容器、设备或编解码器。私有 选项列在各自的容器/设备/编解码器下。

例如，要向 MP3 文件写入 ID3v2.3 头，而不是默认的 ID3v2.4，请使用 MP3 复用器的 id3v2_version 私有选项： 

ffmpeg -i input.flac -id3v2_version 3 out.mp3

所有编解码器的 AVOptions 都是按流的，因此应为它们 附加一个流标识符： 

ffmpeg -i multichannel.mxf -map 0:v:0 -map 0:a:0 -map 0:a:0 -c:a:0 ac3 -b:a:0 640k -ac:a:1 2 -c:a:1 aac -b:2 128k out.mp4

在上面的示例中，一个多声道音频流被两次映射到输出。 第一个实例使用编解码器 ac3 和码率 640k 编码。 第二个实例被缩混为 2 声道并使用编解码器 aac 编码。使用 输出流的绝对索引为其指定了 128k 的码率。

注意：-nooption 语法不能用于布尔的 AVOptions，请使用 -option 0/-option 1。

注意：通过给选项名加上 v/a/s 前缀来指定按流 AVOptions 的 旧有未记录方式现在已过时，并将 很快移除。

3.4 主要选项# TOC

-f format

强制使用指定的格式。

-unit

显示所显示值的单位。

-prefix

对显示的值使用 SI 前缀。 除非使用 "-byte_binary_prefix" 选项，否则所有 前缀都是十进制的。

-byte_binary_prefix

对字节值强制使用二进制前缀。

-sexagesimal

对时间值使用六十进制格式 HH:MM:SS.MICROSECONDS。

-pretty

美化所显示值的格式，它对应于 选项 "-unit -prefix -byte_binary_prefix -sexagesimal"。

-output_format, -of, -print_format writer_name[=writer_options]

设置输出打印格式。

writer_name 指定写出器的名称，而 writer_options 指定要传递给该写出器的选项。

例如，要以 JSON 格式打印输出，请指定： 

-output_format json

有关可用输出打印格式的更多详细信息，请参见下面的 写出器一节。

-sections

打印节结构和节信息，然后退出。该输出 并非供机器解析之用。

-select_streams stream_specifier

仅选择由 stream_specifier 指定的流。此 选项仅影响与流相关的选项 （例如 show_streams、show_packets 等）。

例如，要仅显示音频流，可以使用此命令： 

ffprobe -show_streams -select_streams a INPUT

要仅显示属于索引为 1 的视频流的视频数据包： 

ffprobe -show_packets -select_streams v:1 INPUT
-show_data

以十六进制和 ASCII 转储的形式显示净荷数据（可使用 -data_dump_format 选择其他格式）。与 -show_packets 配合使用时，它会转储数据包的数据。与 -show_streams 配合使用时，它会转储编解码器附加数据。

该转储作为 "data" 字段打印。它可能包含换行符。

-show_data_hash algorithm

显示净荷数据的哈希：对数据包使用 -show_packets， 对编解码器附加数据使用 -show_streams。

-data_dump_format format

选择用于由 -show_data 选项启用的数据转储的格式。 默认为 xxd，这是一种与众所周知的 xxd 程序兼容的十六进制转储格式。也支持 base64。

-show_error

显示在尝试探测输入时发现的错误信息。

错误信息打印在名为 "ERROR" 的节中。

-show_format

显示关于输入多媒体流的容器格式 的信息。

所有容器格式信息都打印在名为 "FORMAT" 的节中。

-show_entries section_entries

设置要显示的条目列表。

条目按以下 语法指定。section_entries 包含一个节条目列表， 各条目之间以 : 分隔。每个节条目由一个节 名称（或唯一名称）组成，其后可选地跟一个该节局部的 条目列表，各条目之间以 , 分隔。

如果指定了节名称但其后没有 =，则 所有条目都会连同所有包含的节一起打印到输出。 否则只打印局部节条目列表中指定的条目。 特别地，如果指定了 = 但 局部条目列表为空，则该节不会 显示任何条目。

请注意，局部节条目的指定顺序 在输出中不会被遵循，将 保留通常的显示顺序。

形式语法如下： 

LOCAL_SECTION_ENTRIES ::= SECTION_ENTRY_NAME[,LOCAL_SECTION_ENTRIES]
SECTION_ENTRY         ::= SECTION_NAME[=[LOCAL_SECTION_ENTRIES]]
SECTION_ENTRIES       ::= SECTION_ENTRY[:SECTION_ENTRIES]

例如，要仅显示每个流的索引和类型，以及数据包的 PTS 时间、持续时间时间和流索引，可以指定 以下参数： 

packet=pts_time,duration_time,stream_index : stream=index,codec_type

要显示 "format" 节中的所有条目，但只显示 "stream" 节中的编解码器类型，请指定以下参数： 

format : stream=codec_type

要显示 stream 和 format 节中的所有标签： 

stream_tags : format_tags

要仅显示 stream 节中的 title 标签（如果可用）： 

stream_tags=title
-show_packets

显示输入多媒体流中包含的每个数据包的信息。

每个单独数据包的信息打印在名为 "PACKET" 的专属节中。

-show_frames

显示输入多媒体流中包含的每个帧和字幕的信息。

每个单独帧的信息打印在名为 "FRAME" 或 "SUBTITLE" 的专属节中。

-show_log loglevel

按照 loglevel 中设置的值显示解码器关于每个帧的日志信息（参见 -loglevel）。此选项需要 -show_frames。

每条日志消息的信息打印在名为 "LOG" 的专属节中。

-show_streams

显示输入多媒体流中包含的每个媒体流的信息。

每个媒体流的信息打印在名为 "STREAM" 的专属节中。

-show_programs

显示输入多媒体流中包含的节目及其流的信息。

每个媒体流的信息打印在名为 "PROGRAM_STREAM" 的专属节中。

-show_stream_groups

显示输入多媒体流中包含的流组及其流的信息。

每个媒体流的信息打印在名为 "STREAM_GROUP_STREAM" 的专属节中。

-show_chapters

显示格式中存储的章节的信息。

每个章节打印在名为 "CHAPTER" 的专属节中。

-count_frames

统计每个流的帧数，并在相应的流节中报告。

-count_packets

统计每个流的数据包数，并在相应的流节中报告。

-read_intervals read_intervals

仅读取指定的区间。read_intervals 必须是一个由 "," 分隔的区间规格说明序列。ffprobe 将定位到区间起点，并从该处继续读取。

每个区间由两个可选部分组成，二者以 "%" 分隔。

第一部分指定区间起始位置。它被解释为绝对位置；若其前面带有 "+" 字符，则被解释为相对于当前位置的偏移量。如果未指定第一部分，则在读取该区间时不会执行定位。

第二部分指定区间结束位置。它被解释为绝对位置；若其前面带有 "+" 字符，则被解释为相对于当前位置的偏移量。如果偏移量规格以 "#" 开头，则被解释为从区间起点开始要读取的数据包数量（不包括冲刷数据包）。如果未指定第二部分，程序将一直读取到输入的末尾。

请注意，定位并不精确，因此实际的区间起点可能与指定的位置不同。此外，当指定了区间时长时，绝对结束时间是通过把时长加到由文件定位而找到的区间起点上来计算的，而不是加到指定的起始值上。

形式语法如下： 

INTERVAL  ::= [START|+START_OFFSET][%[END|+END_OFFSET]]
INTERVALS ::= INTERVAL[,INTERVALS]

下面给出几个示例。

  • 定位到时间 10，读取数据包直到所找到的定位点之后 20 秒，然后定位到位置 01:30（1 分 30 秒）并读取数据包直到位置 01:45。 
    10%+20,01:30%01:45
  • 定位到位置 01:23 之后仅读取 42 个数据包： 
    01:23%+#42
  • 从头开始仅读取前 20 秒： 
    %+20
  • 从头读取直到位置 02:30： 
    %02:30
-show_private_data, -private

显示私有数据，即取决于所显示的特定元素的格式的数据。此选项默认启用，但在特定用途下可能需要将其禁用，例如在创建符合 XSD 的 XML 输出时。

-show_program_version

显示与程序版本相关的信息。

版本信息打印在名为 "PROGRAM_VERSION" 的节中。

-show_library_versions

显示与库版本相关的信息。

每个库的版本信息打印在名为 "LIBRARY_VERSION" 的节中。

-show_versions

显示与程序和库版本相关的信息。这相当于同时设置 -show_program_version 和 -show_library_versions 两个选项。

-show_pixel_formats

显示 FFmpeg 支持的所有像素格式的信息。

每种格式的像素格式信息打印在名为 "PIXEL_FORMAT" 的节中。

-show_optional_fields value

某些写出器（即 JSON 和 XML）会省略打印取值无效或不适用的字段，而其他写出器则总是打印它们。此选项可用于控制这一行为。有效值为 always/1、never/0 和 auto/-1。默认值为 auto。

-analyze_frames

分析帧和/或它们的边数据，范围不超过所提供的读取区间，从而提供在流层面可能有用的附加信息。必须与 -show_streams 选项配合使用，否则不会产生任何效果。

目前，启用此选项时提供的附加字段为 closed_captions 和 film_grain 字段。

例如，要分析前 20 秒并填充这些字段： 

ffprobe -show_streams -analyze_frames -read_intervals "%+20" INPUT
-bitexact

强制 bitexact 输出，用于产生不依赖于特定构建的输出。

-i input_url

读取 input_url。

-o output_url

将输出写入 output_url。如果未指定，输出将发送到 stdout。

-c:media_specifier codec_name
-codec:media_specifier codec_name

为 media_specifier 所标识的流强制使用特定的解码器实现，该参数可以取值 a（音频）、v（视频）、s（字幕）和 d（数据）。

4 写出器# TOC

写出器定义 ffprobe 所采用的输出格式，并用于打印输出的所有部分。

写出器可以接受一个或多个参数，用以指定要采用的选项。选项以 key=value 对列表的形式指定，以 ":" 分隔。

所有写出器都支持以下选项：

string_validation, sv

设置字符串校验模式。

接受以下取值。

‘fail’

如果在输入中发现无效的字符串（UTF-8）序列或码点，写出器会立即失败。这对于校验输入元数据尤其有用。

‘ignore’

任何校验错误都将被忽略。这可能导致输出损坏，尤其是在使用 json 或 xml 写出器时。

‘replace’

写出器会用 string_validation_replacement 指定的字符串替换无效的 UTF-8 序列或码点。

默认值为 ‘replace’。

string_validation_replacement, svr

设置在 string_validation 被设为 ‘replace’ 时使用的替换字符串。

如果未指定该选项，写出器将采用空字符串，也就是说会从输入字符串中移除无效序列。

下面介绍当前可用的各个写出器。

4.1 default# TOC

默认格式。

按以下形式打印每个节： 

[SECTION]
key1=val1
...
keyN=valN
[/SECTION]

元数据标签会作为一行打印在对应的 FORMAT、STREAM、 STREAM_GROUP_STREAM 或 PROGRAM_STREAM 节中，并以字符串 "TAG:" 作为前缀。

下面介绍可接受的选项。

nokey, nk

若设为 1，表示不打印每个字段的键。默认值为 0。

noprint_wrappers, nw

若设为 1，表示不打印节的头部和尾部。 默认值为 0。

4.2 compact, csv# TOC

紧凑与 CSV 格式。

csv 写出器等价于 compact，但支持 不同的默认值。

每个节都打印在一行上。 如果未指定任何选项，输出的形式为： 

section|key1=val1| ... |keyN=valN

元数据标签打印在对应的 "format" 或 "stream" 节中。元数据标签的键若被打印，会以字符串 "tag:" 作为前缀。

下面介绍可接受的选项。

item_sep, s

指定用于分隔输出行中各字段的字符。 它必须是单个可打印字符，默认为 "|"（对 csv 写出器为 ","）。

nokey, nk

若设为 1，表示不打印每个字段的键。其默认 值为 0（对 csv 写出器为 1）。

escape, e

设置要使用的转义模式，默认为 "c"（对 csv 写出器为 "csv"）。

它可以取以下取值之一：

c

执行类 C 转义。包含换行符（‘\n’）、回车 符（‘\r’）、制表符（‘\t’）、换页符（‘\f’）、转义 字符（‘\’）或条目分隔字符 SEP 的字符串会使用 类 C 风格的转义进行处理，从而换行符被转换为 序列 ‘\n’，回车符转换为 ‘\r’，‘\’ 转换为 ‘\\’， 而分隔符 SEP 转换为 ‘\SEP’。

csv

执行类 CSV 转义，如 RFC4180 所述。包含 换行符（‘\n’）、回车符（‘\r’）、双引号 （‘"’）或 SEP 的字符串会被包裹在双引号中。

none

不执行任何转义。

print_section, p

若该值为 1，则在每行开头打印节名称；将该值设为 0 可禁用它。默认值为 1。

4.3 flat# TOC

扁平格式。

一种自由形式的输出，其中每行都包含一个显式的 key=value，例如 "streams.stream.3.tags.foo=bar"。该输出经过 shell 转义，因此只要 分隔字符是字母数字字符或下划线（参见 sep_char 选项）， 就可以直接嵌入 sh 脚本中。

下面介绍可接受的选项。

sep_char, s

用于在打印出的字段键中分隔章、节名称、ID 以及 可能存在的标签的分隔字符。

默认值为 ‘.’。

hierarchical, h

指定节名称的表示是否应采用层级形式。若 设为 1，且当前 章中有多个节，则节名称会以 章名作为前缀。取值为 0 将禁用此行为。

默认值为 1。

4.4 ini# TOC

INI 格式输出。

以基于 INI 的格式打印输出。

采用以下约定：

  • 所有键和值都是 UTF-8
  • ‘.’ 是子组分隔符
  • 换行符、‘\t’、‘\f’、‘\b’ 以及下列字符会被 转义
  • ‘\’ 是转义字符
  • ‘#’ 是注释指示符
  • ‘=’ 是键=值分隔符
  • ‘:’ 未被使用，但通常被解析为键=值分隔符

该写出器接受的选项是一个 key=value 对列表， 以 ‘:’ 分隔。

所接受选项的说明如下。

hierarchical, h

指定节名称的命名是否应分层。若 设为 1，且当前章中存在多个节， 则节名称将加上章名前缀。 值为 0 会禁用此行为。

默认值为 1。

4.5 json# TOC

基于 JSON 的格式。

每个节都使用 JSON 记法打印。

所接受选项的说明如下。

compact, c

若设为 1 则启用紧凑输出，即每个节都将 打印在单行上。默认值为 0。

关于 JSON 的更多信息，请参见 http://www.json.org/。

4.6 xml# TOC

基于 XML 的格式。

XML 输出在安装于 FFmpeg 数据目录中的 XML schema 描述文件 ffprobe.xsd 中有说明。

该 schema 的更新版本可从 URL http://www.ffmpeg.org/schema/ffprobe.xsd 获取，该地址会重定向到 提交进 FFmpeg 开发源代码树的最新 schema。

请注意，只有在未指定特殊全局输出选项 （unit、prefix、byte_binary_prefix、 sexagesimal 等）时，输出的内容才会符合 ffprobe.xsd schema。

所接受选项的说明如下。

fully_qualified, q

若设为 1，则指定输出是否应完全限定。默认 值为 0。 生成可通过 XSD 文件校验的 XML 文件时需要此项。

xsd_strict, x

若设为 1，则执行更多检查以确保输出 符合 XSD。默认值为 0。 此选项会自动将 fully_qualified 设为 1。

关于 XML 格式的更多信息，请参见 https://www.w3.org/XML/。

5 时间码# TOC

ffprobe 支持时间码提取：

  • MPEG1/2 时间码从 GOP 中提取，可在视频 流详情中获得（-show_streams，参见 timecode）。
  • MOV 时间码从 tmcd 轨道中提取，因此可在 tmcd 流元数据中获得（-show_streams，参见 TAG:timecode）。
  • DV、GXF 和 AVI 时间码可在格式元数据 中获得（-show_format，参见 TAG:timecode）。
