1 概要# TOC

ffplay [options] [input_url]

2 描述# TOC

FFplay 是一个非常简洁且可移植的媒体播放器，它使用 FFmpeg 库和 SDL 库。它主要用作各种 FFmpeg API 的 测试平台。

3 选项# TOC

所有数值选项，除非另有说明，都接受一个字符串 表示数字作为输入，其后可以跟一个 SI 单位前缀，例如：’K’、’M’ 或 ’G’。

如果在 SI 单位前缀后附加 ’i’，整个前缀将被 解释为二进制倍数的单位前缀，它们基于 1024 的幂而非 1000 的幂。在 SI 单位 前缀后附加 ’B’ 会将数值乘以 8。这样就可以使用例如： ’KB’、’MiB’、’G’ 和 ’B’ 作为数字后缀。

不接受参数的选项是布尔选项，会把 相应的值设为 true。可以通过在选项名前加上 "no" 将它们 设为 false。例如使用 "-nofoo" 会把名为 "foo" 的布尔选项设为 false。

接受参数的选项支持一种特殊语法：命令行上 给出的参数被解释为文件的路径，实际的 参数值从该文件加载。要使用此功能，请在选项名之前 （前导短横线之后）紧接一个正斜杠 ’/’。例如 

ffmpeg -i INPUT -/filter:v filter.script OUTPUT

将从名为 filter.script 的文件加载滤镜图描述。

3.1 流标识符# TOC

有些选项是按流生效的，例如码率或编解码器。流标识符 用于精确指定某个给定选项属于哪些流。

流标识符是一个通常附加在选项名之后并 用冒号与之分隔的字符串。例如 -codec:a:1 ac3 包含 a:1 流标识符，它匹配第二个音频流。因此，它 将为第二个音频流选择 ac3 编解码器。

一个流标识符可以匹配多个流，从而使该选项应用于 所有这些流。例如 -b:a 128k 中的流标识符匹配所有音频 流。

空的流标识符匹配所有流。例如，-codec copy 或 -codec: copy 会复制所有流而不重新编码。

流标识符可能的形式有：

stream_index

匹配具有该索引的流。例如 -threads:1 4 会把 第二个流的线程数设为 4。如果 stream_index 用作 附加流标识符（见下文），那么它从匹配的流中选择编号为 stream_index 的流。流编号基于 libavformat 检测到的流的顺序，除非同时指定了流组 标识符或节目 ID。在这种情况下，它基于 流在该组或节目中的顺序。

stream_type[:additional_stream_specifier]

stream_type 是以下之一：’v’ 或 ’V’ 表示视频，’a’ 表示音频，’s’ 表示字幕，’d’ 表示数据，’t’ 表示附件。’v’ 匹配所有视频 流，’V’ 只匹配不是附加图片、视频 缩略图或封面图的视频流。如果使用了 additional_stream_specifier，那么 它匹配既具有该类型又匹配 additional_stream_specifier 的流。否则，它匹配 指定类型的所有流。

g:group_specifier[:additional_stream_specifier]

匹配组标识符为 group_specifier 的组中的流。 如果使用了 additional_stream_specifier，那么它匹配既 属于该组又匹配 additional_stream_specifier 的流。 group_specifier 可以是以下之一：

group_index

匹配具有该组索引的流。

#group_id or i:group_id

匹配具有该组 id 的流。

p:program_id[:additional_stream_specifier]

匹配 id 为 program_id 的节目中的流。如果 使用了 additional_stream_specifier，那么它匹配既 属于该节目又匹配 additional_stream_specifier 的流。

#stream_id or i:stream_id

按流 id 匹配流（例如 MPEG-TS 容器中的 PID）。

m:key[:value]

匹配元数据标签 key 具有指定值的流。如果 未给出 value，则匹配包含给定标签且值 任意的流。key 或 value 中的冒号字符 ’:’ 需要 用反斜杠转义。

disp:dispositions[:additional_stream_specifier]

匹配具有给定处置方式（disposition）的流。dispositions 是一个 或多个处置方式的列表（由 -dispositions 选项打印）， 用 ’+’ 连接。

u

匹配具有可用配置的流，编解码器必须已定义，并且 视频尺寸或音频采样率等必要信息必须存在。

请注意，在 ffmpeg 中，按元数据匹配只对 输入文件正常生效。

3.2 通用选项# TOC

这些选项由所有 ff* 工具共享。

-L, -license

显示许可证。

-h, -?, -help, --help [arg]

显示帮助。可以指定一个可选参数，用于打印关于某个特定 条目的帮助信息。如果未指定参数，则只显示基本的（非高级） 工具选项。

arg 的可能取值有：

long

在基本工具选项之外，额外打印高级工具选项。

full

打印完整的选项列表，包括编码器、解码器、解复用器、复用器、滤镜 等的共享选项和私有选项。

decoder=decoder_name

打印名为 decoder_name 的解码器的详细信息。使用 -decoders 选项可获取所有解码器的列表。

encoder=encoder_name

打印名为 encoder_name 的编码器的详细信息。使用 -encoders 选项可获取所有编码器的列表。

demuxer=demuxer_name

打印名为 demuxer_name 的解复用器的详细信息。使用 -formats 选项可获取所有解复用器和复用器的列表。

muxer=muxer_name

打印名为 muxer_name 的复用器的详细信息。使用 -formats 选项可获取所有复用器和解复用器的列表。

filter=filter_name

打印名为 filter_name 的滤镜的详细信息。使用 -filters 选项可获取所有滤镜的列表。

bsf=bitstream_filter_name

打印名为 bitstream_filter_name 的比特流滤波器的详细信息。 使用 -bsfs 选项可获取所有比特流滤波器的列表。

protocol=protocol_name

打印名为 protocol_name 的协议的详细信息。 使用 -protocols 选项可获取所有协议的列表。

-version

显示版本。

-buildconf

显示构建配置，每行一个选项。

-formats

显示可用的格式（包括设备）。

-demuxers

显示可用的解复用器。

-muxers

显示可用的复用器。

-devices

显示可用的设备。

-codecs

显示 libavcodec 已知的所有编解码器。

请注意，本文档中通篇使用术语 ’codec’ 作为简称，用以指代 更准确地称为媒体比特流格式的东西。

-decoders

显示可用的解码器。

-encoders

显示所有可用的编码器。

-bsfs

显示可用的比特流滤波器。

-protocols

显示可用的协议。

-filters

显示可用的 libavfilter 滤镜。

-pix_fmts

显示可用的像素格式。

-sample_fmts

显示可用的采样格式。

-layouts

显示声道名称和标准声道布局。

-dispositions

显示流的处置信息。

-colors

显示可识别的颜色名称。

-sources device[,opt1=val1[,opt2=val2]...]

显示输入设备自动检测到的源。 某些设备可能提供依赖系统的源名称，这些名称无法被自动检测。 不能假定返回的列表始终是完整的。 

ffmpeg -sources pulse,server=192.168.0.4
-sinks device[,opt1=val1[,opt2=val2]...]

显示输出设备自动检测到的接收端（sink）。 某些设备可能提供依赖系统的接收端名称，这些名称无法被自动检测。 不能假定返回的列表始终是完整的。 

ffmpeg -sinks pulse,server=192.168.0.4
-loglevel [flags+]loglevel | -v [flags+]loglevel

设置库所使用的日志级别和标志。

可选的 flags 前缀可以包含以下取值：

‘repeat’

表示重复的日志输出不应被压缩到第一行， 并且将省略 "Last message repeated n times" 这一行。

‘level’

表示日志输出应为每条消息行添加 [level] 前缀。 这可以作为日志着色的一种替代方式，例如在把日志 转储到文件时。

‘time’

表示日志行应加上时间信息前缀。

‘datetime’

表示日志行应加上日期和时间信息前缀。

标志也可以单独使用，只需在单个标志前加上 ’+’/’-’ 前缀即可设置/重置该标志， 而不影响其他 flags，也不改变 loglevel。同时设置 flags 和 loglevel 时，应在最后一个 flags 值 与 loglevel 之间使用 ’+’ 分隔符。

loglevel 是一个字符串或数字，其取值为下列之一：

‘quiet, -8’

完全不显示任何内容；保持静默。

‘panic, 0’

只显示可能导致进程崩溃的致命错误，例如 断言失败。此级别目前不用于任何用途。

‘fatal, 8’

只显示致命错误。这类错误发生之后进程绝对 无法继续。

‘error, 16’

显示所有错误，包括可以恢复的错误。

‘warning, 24’

显示所有警告和错误。任何与可能不正确或意外事件 相关的消息都会显示。

‘info, 32’

在处理过程中显示提示性消息。这是在警告和错误之外 额外显示的内容。这是默认值。

‘verbose, 40’

与 info 相同，只是更详细。

‘debug, 48’

显示所有内容，包括调试信息。

‘trace, 56’

例如，要启用重复日志输出，请添加 level 前缀，并将 loglevel 设置为 verbose： 

ffmpeg -loglevel repeat+level+verbose -i input output

另一个例子：在不影响 level 前缀标志或 loglevel 的 当前状态的情况下启用重复日志输出： 

ffmpeg [...] -loglevel +repeat

默认情况下，程序将日志输出到 stderr。如果终端支持着色， 则会用颜色标记错误和警告。可以通过设置环境变量 AV_LOG_FORCE_NOCOLOR 禁用日志着色，也可以通过设置 环境变量 AV_LOG_FORCE_COLOR 强制启用。

-report

将完整的命令行和日志输出转储到当前目录下名为 program-YYYYMMDD-HHMMSS.log 的文件中。 该文件对提交 bug 报告很有用。 它同时隐含 -loglevel debug。

将环境变量 FFREPORT 设置为任意值具有相同的 效果。如果该值是以 ’:’ 分隔的 key=value 序列，这些 选项将影响报告；如果选项值中包含特殊字符或选项分隔符 ’:’， 则必须对选项值进行转义（参见 ffmpeg-utils 手册中的 “引用与转义” 一节）。

可识别以下选项：

file

设置报告要使用的文件名；%p 会展开为程序 名，%t 会展开为时间戳，%% 会展开 为普通的 %

level

使用数值设置日志详细程度级别（参见 -loglevel）。

例如，要以日志级别 32（日志级别 info 的别名） 将报告输出到名为 ffreport.log 的文件： 

FFREPORT=file=ffreport.log:level=32 ffmpeg -i input output

解析环境变量时出现的错误不是致命错误，也不会 出现在报告中。

-hide_banner

禁止打印横幅信息。

所有 FFmpeg 工具通常都会显示版权声明、编译选项 和库版本信息。可以使用此选项禁止打印 这些信息。

-cpuflags flags (global)

允许设置和清除 cpu 标志。此选项仅用于 测试。除非你清楚自己在做什么，否则不要使用它。 

ffmpeg -cpuflags -sse+mmx ...
ffmpeg -cpuflags mmx ...
ffmpeg -cpuflags 0 ...

‘mmxext’
‘sse’
‘sse2’
‘sse2slow’
‘sse3’
‘sse3slow’
‘ssse3’
‘atom’
‘sse4.1’
‘sse4.2’
‘avx’
‘avx2’
‘xop’
‘fma3’
‘fma4’
‘3dnow’
‘3dnowext’
‘bmi1’
‘bmi2’
‘cmov’
‘ARM’
‘armv5te’
‘armv6’
‘armv6t2’
‘vfp’
‘vfpv3’
‘neon’
‘setend’
‘AArch64’
‘armv8’
‘vfp’
‘neon’
‘PowerPC’
‘altivec’
‘Specific Processors’
‘pentium2’
‘pentium3’
‘pentium4’
‘k6’
‘k62’
‘athlon’
‘athlonxp’
‘k8’
-cpucount count (global)

覆盖对 CPU 数量的检测。此选项仅用于 测试。除非你清楚自己在做什么，否则不要使用它。 

ffmpeg -cpucount 2
-max_alloc bytes

设置 ffmpeg 的 malloc 函数族在堆上分配内存块的最大大小 限制。使用此选项时请极其谨慎。如果你不了解这样做 带来的全部后果，请不要使用。 默认值为 INT_MAX。

3.3 AVOptions# TOC

这些选项由 libavformat、libavdevice 和 libavcodec 库直接提供。要查看可用的 AVOptions 列表，请使用 -help 选项。它们分为两类：

generic

这些选项可为任何容器、编解码器或设备设置。通用选项 在容器/设备下列于 AVFormatContext 选项之下，在 编解码器下列于 AVCodecContext 选项之下。

private

这些选项特定于给定的容器、设备或编解码器。私有 选项列在各自对应的容器/设备/编解码器之下。

例如，要向 MP3 文件写入 ID3v2.3 头部而不是默认的 ID3v2.4， 请使用 MP3 复用器的 id3v2_version 私有 选项： 

ffmpeg -i input.flac -id3v2_version 3 out.mp3

所有编解码器 AVOptions 都是按流生效的，因此应为它们附加 流标识符： 

ffmpeg -i multichannel.mxf -map 0:v:0 -map 0:a:0 -map 0:a:0 -c:a:0 ac3 -b:a:0 640k -ac:a:1 2 -c:a:1 aac -b:2 128k out.mp4

在上面的例子中，一个多声道音频流被映射了两次用于输出。 第一个实例使用编解码器 ac3 编码，码率为 640k。 第二个实例被缩混为 2 个声道，并使用编解码器 aac 编码。通过 输出流的绝对索引为它指定了 128k 的码率。

注意：-nooption 语法不能用于布尔型 AVOptions，请使用 -option 0/-option 1。

注意：通过在选项名前加 v/a/s 来指定按流 AVOptions 的 旧有未文档化方式现已废弃，并将在 不久后移除。

3.4 主要选项# TOC

-x width

强制显示的宽度。

-y height

强制显示的高度。

-fs

以全屏模式启动。

-an

禁用音频。

-vn

禁用视频。

-sn

禁用字幕。

-ss pos

定位到 pos。请注意，在大多数格式中无法精确 定位，因此 ffplay 会定位到最接近 pos 的定位点。

pos 必须是一个时间时长规格， 参见 ffmpeg-utils(1) 手册中的时间时长一节。

-t duration

播放 duration 秒的音频/视频。

duration 必须是一个时间时长规格， 参见 ffmpeg-utils(1) 手册中的时间时长一节。

-bytes

按字节定位。

-seek_interval

设置使用左/右方向键定位时的自定义间隔，单位为秒。默认值为 10 秒。

-nodisp

禁用图形显示。

-noborder

无边框窗口。

-alwaysontop

窗口始终置顶。可用于：带 SDL >= 2.0.5 的 X11、Windows SDL >= 2.0.6。

-volume

设置启动音量。0 表示静音，100 表示不做音量衰减或 放大。负值按 0 处理，大于 100 的值按 100 处理。

-f fmt

强制使用格式。

-window_title title

设置窗口标题（默认为输入文件名）。

-left title

设置窗口左边缘的 x 坐标（默认为窗口居中）。

-top title

设置窗口上边缘的 y 坐标（默认为窗口居中）。

-loop number

将影片播放循环 <number> 次。0 表示无限循环。

-showmode mode

设置要使用的显示模式。 mode 的可用取值为：

‘0, video’

显示视频

‘1, waves’

显示音频波形

‘2, rdft’

使用 RDFT（（逆）实离散傅里叶变换）显示音频频带

默认值为 "video"，如果视频不存在或无法播放， 则自动选择 "rdft"。

你可以通过按 w 键在可用的显示模式之间 交互式循环切换。

-vf filtergraph

创建由 filtergraph 指定的滤镜图，并用它对 视频流进行滤镜处理。

filtergraph 是要应用于该流的滤镜图的描述， 它必须有一个视频输入和一个视频 输出。在滤镜图中，输入端关联到标签 in，输出端关联到标签 out。有关滤镜图 语法的更多信息，请参见 ffmpeg-filters 手册。

你可以多次指定该参数，并通过按 w 键在指定的 滤镜图与显示模式之间循环切换。

-af filtergraph

filtergraph 是要应用于输入音频的 滤镜图的描述。 使用 "-filters" 选项可显示所有可用的滤镜（包括 源和汇）。

-i input_url

读取 input_url。

3.5 高级选项# TOC

-stats

打印若干播放统计信息，特别是显示流 时长、编解码器参数、流中的当前位置以及 音频/视频同步偏移。默认会显示，除非 日志级别低于 info。可以通过手动 指定此选项来强制显示。要禁用它，需要指定 -nostats。

-fast

不符合规范的优化。

-genpts

生成 pts。

-sync type

将主时钟设置为音频（type=audio）、视频 （type=video）或外部（type=ext）。默认为音频。主 时钟用于控制音视频同步。大多数媒体 播放器使用音频作为主时钟，但在某些情况下（流式传输或高 质量广播）有必要改变这一点。此选项主要 用于调试目的。

-ast audio_stream_specifier

使用给定的流标识符选择所需的音频流。流 标识符在 流标识符 一章中描述。如果此选项 未指定，则会在已选视频流所属的节目中 选择“最佳”音频流。

-vst video_stream_specifier

使用给定的流标识符选择所需的视频流。流 标识符在 流标识符 一章中描述。如果此选项 未指定，则会选择“最佳”视频流。

-sst subtitle_stream_specifier

使用给定的流标识符选择所需的字幕流。流 标识符在 流标识符 一章中描述。如果此选项 未指定，则会在已选视频流或音频流所属的节目中 选择“最佳”字幕流。

-autoexit

视频播放完毕时退出。

-exitonkeydown

按下任意键时退出。

-exitonmousedown

按下任意鼠标键时退出。

-codec:media_specifier codec_name

为由 media_specifier 标识的流强制使用特定的解码器实现， 它可以取以下值：a（音频）、 v（视频）和 s（字幕）。

-acodec codec_name

强制使用特定的音频解码器。

-vcodec codec_name

强制使用特定的视频解码器。

-scodec codec_name

强制使用特定的字幕解码器。

-autorotate

根据文件元数据自动旋转视频。默认启用， 使用 -noautorotate 禁用它。

-framedrop

当视频不同步时丢弃视频帧。如果主时钟未设置为视频，则默认 启用。使用此选项可为所有主时钟来源启用丢帧， 使用 -noframedrop 禁用它。

-infbuf

不限制输入缓冲区大小，尽快从输入中读取尽可能多的数据。 对于实时流默认启用，因为如果数据未被及时读取， 数据可能会被丢弃。使用此选项可为所有输入启用 无限缓冲区，使用 -noinfbuf 禁用它。

-filter_threads nb_threads

定义使用多少个线程来处理一条滤镜管线。每条管线 都会创建一个线程池，其中包含这么多可用于并行 处理的线程。默认值为 0，这意味着线程数将由 可用 CPU 的数量决定。

-enable_vulkan

使用 vulkan 渲染器而非 SDL 内置渲染器。依赖于 libplacebo。

-vulkan_params

使用以 ":" 分隔的 key=value 对列表进行 Vulkan 配置。

-hwaccel

使用硬件加速解码。启用此选项将自动启用 vulkan 渲染器。

-video_bg pattern

设置用于透明视频的视频背景图案。对于纯色 图案，可以使用 ffmpeg-utils(1) 手册中的颜色一节 中指定的颜色名称或颜色代码。 还可以使用特殊关键字 tiles 来表示棋盘格风格的 图案。这也是默认值。none 图案在不进行 alpha 混合的 情况下渲染，实际上忽略 alpha 通道。
