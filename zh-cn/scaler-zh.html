1 描述# TOC

FFmpeg 重缩放器为 libswscale 库的 图像转换工具提供高层接口。特别地，它允许执行 图像重缩放和像素格式转换。

2 缩放器选项# TOC

视频缩放器支持以下具名选项。

可以在 FFmpeg 工具中通过指定 -option value 来设置选项， 仅有下面说明的少数几个仅限 API 的例外。 对于程序化使用，可以在 SwsContext 选项中显式设置，或通过 libavutil/opt.h API 设置。

scaler, scaler_sub

选择要使用的缩放算法。两者的默认值都是 ‘auto’。 它接受以下取值：

‘auto’

自动选择。对于 ‘scaler_sub’，它表示与 ‘scaler’ 相同的算法。对于 ‘scaler’，它默认为由 ‘sws_flags’ 所选择的缩放器标志。

‘bilinear’

双线性滤波器。（又称三角形滤波器）

‘bicubic’

2 抽头三次 BC 样条（又称 Mitchell-Netravali 样条）。B 和 C 参数可以通过 设置 param0 和 param1 来配置， 默认值分别为 0.0 和 0.6。

‘point, neighbor’

点采样（又称最近邻）。

‘area’

区域平均。在放大时等效于 ‘bilinear’。

‘gaussian’

2 抽头高斯滤波器近似。锐度参数可以通过设置 param0 来配置，默认值为 3.0。

‘sinc’

未加窗的 sinc 滤波器。

‘lanczos’

Lanczos 重采样（加窗 sinc）。滤波器抽头数可以通过设置 param0 来配置，默认值为 3。

‘spline’

未加窗的自然双三次样条。

sws_flags

设置缩放器标志。它也曾用于设置缩放算法， 但该用法已被弃用，建议改用设置 ‘scaler’。 只能选择一种算法。默认值为 ‘bicubic’。

它接受以下取值：

‘fast_bilinear’

选择快速双线性缩放算法。（已弃用）

‘bilinear’

选择双线性缩放算法。（已弃用）

‘bicubic’

选择双三次缩放算法。（已弃用）

‘experimental’

选择实验性缩放算法。（已弃用）

‘neighbor’

选择最近邻重缩放算法。（已弃用）

‘area’

选择区域平均重缩放算法。（已弃用）

‘bicublin’

对亮度分量选择双三次缩放算法， 对色度分量选择双线性。（已弃用）

‘gauss’

选择高斯重缩放算法。（已弃用）

‘sinc’

选择 sinc 重缩放算法。（已弃用）

‘lanczos’

选择 Lanczos 重缩放算法。默认宽度（alpha）为 3， 可以通过设置 param0 来更改。（已弃用）

‘spline’

选择自然双三次样条重缩放算法。（已弃用）

‘print_info’

启用打印/调试日志记录。

‘accurate_rnd’

启用精确舍入。

‘full_chroma_int’

启用全色度插值。

‘full_chroma_inp’

选择全色度输入。

‘bitexact’

启用比特精确输出。

‘unstable’

允许使用实验性的新代码。可能会对输出产生细微影响， 甚至产生错误结果。仅供测试。

srcw (API only)

设置源宽度。

srch (API only)

设置源高度。

dstw (API only)

设置目标宽度。

dsth (API only)

设置目标高度。

src_format (API only)

设置源像素格式（必须用整数表示）。

dst_format (API only)

设置目标像素格式（必须用整数表示）。

src_range (boolean)

如果该值设为 1，表示源为全范围。默认值为 0，表示源为有限范围。

dst_range (boolean)

如果该值设为 1，则为目标启用全范围。 默认值为 0，即启用有限范围。

gamma (boolean)

如果该值设为 1，则启用 gamma 校正缩放。默认值为 0。

param0, param1

设置缩放算法参数。所指定的值专用于某些 缩放算法，会被其它算法忽略。 所指定的值为浮点数。

sws_dither

设置抖动算法。接受以下取值之一。 默认值为 ‘auto’。

‘auto’

自动选择

‘none’

不抖动

‘bayer’

bayer 抖动

‘ed’

误差扩散抖动

‘a_dither’

基于加法的算术抖动

‘x_dither’

基于 xor 的算术抖动（随机性更强，图案不如 a_dither 明显）。

alphablend

设置当输入含 alpha 而输出不含 alpha 时要使用的 alpha 混合方式。 默认值为 ‘none’。

‘uniform_color’

混合到统一的背景色上

‘checkerboard’

混合到棋盘格上

‘none’

不混合

sws_backends

设置允许的 swscale 后端。这是一个标志选项， 因此可以组合多个后端。

‘auto’

自动选择。等于 ‘stable’ 或 ‘all’，具体取决于 是否设置了 ‘unstable’ 标志。这是默认值。

‘stable’

所有稳定后端。

‘unstable’

所有不稳定后端。

‘all’

所有可用后端。

‘legacy’

旧版 swscale 代码。

‘c’

基于模板的参考代码。

‘memcpy’

使用 libc memcpy 的快速路径。

‘x86’

x86 SIMD 内核。

‘aarch64’

AArch64 NEON 内核。

‘spirv’

Vulkan SPIR-V 后端。
