本文档介绍一些由 libavutil 库提供的通用特性与实用 工具。

2 语法# TOC

本节介绍 FFmpeg 库和工具所使用的语法 与格式。

2.1 引号与转义# TOC

除非明确说明，FFmpeg 采用以下的引号与转义机制。适用 以下规则：

  • ‘'’ 和 ‘\’ 是特殊字符（分别用 于引号和转义）。除它们之外，根据使用转义和引号的具体语法， 可能还存在其他特殊字符。
  • 特殊字符通过在其前面加上 ‘\’ 来转义。
  • 被 ‘''’ 括起来的所有字符都会按字面原样包含在 解析后的字符串中。引号字符 ‘'’ 本身无法被引用， 因此你可能需要先结束引号再对它进行转义。
  • 前导和尾随空白字符，除非经过转义或加引号，否则会 从解析后的字符串中移除。

请注意，在使用命令行或脚本时，你可能需要再加一层转义，这 取决于所采用的 shell 语言的语法。

libavutil/avstring.h 中定义的函数 av_get_token 可用于按照上述规则解析经过引号或 转义处理的词元。

FFmpeg 源码树中的工具 tools/ffescape 可用于 自动为脚本中的字符串加引号或转义。

2.1.1 示例# TOC

  • 对包含 ' 特殊字符的字符串 Crime d'Amour 进行 转义： 
    Crime d\'Amour
  • 上面的字符串包含一个引号，因此在为它加引号时需要转义 '： 
    'Crime d'\''Amour'
  • 使用引号包含前导或尾随空白字符： 
    '  this string starts and ends with whitespaces  '
  • 转义和引号可以混用： 
    ' The string '\'string\'' is a string '
  • 要包含字面量 ‘\’，可以使用转义或引号： 
    'c:\foo' can be written as c:\\foo

2.2 日期# TOC

可接受的语法为： 

[(YYYY-MM-DD|YYYYMMDD)[T|t| ]]((HH:MM:SS[.m...]]])|(HHMMSS[.m...]]]))[Z]
now

如果该值为 "now"，则取当前时间。

除非附加 Z，否则时间为本地时间；附加 Z 时它 按 UTC 解释。 如果未指定年-月-日部分，则取当前 年-月-日。

2.3 时间长度# TOC

表示时间长度有两种可接受的语法。 

[-][HH:]MM:SS[.m...]

HH 表示小时数，MM 表示分钟数， 最多 2 位数字，SS 表示秒数，最多 2 位数字。末尾的 m 表示 SS 的小数值。

或者 

[-]S+[.m...][s|ms|us]

S 表示秒数，可带可选的小数部分 m。可选的字面后缀 ‘s’、‘ms’ 或 ‘us’ 分别表示将该值解释为秒、毫秒或微秒。

在两种表达式中，可选的 ‘-’ 都表示负的时间长度。

2.3.1 示例# TOC

以下示例都是有效的时间长度：

‘55’

55 秒

‘0.2’

0.2 秒

‘200ms’

200 毫秒，即 0.2 秒

‘200000us’

200000 微秒，即 0.2 秒

‘12:03:45’

12 小时 03 分 45 秒

‘23.189’

23.189 秒

2.6 比例# TOC

比例可以表示为一个表达式，或者采用 numerator:denominator 的形式。

请注意，值为无穷大（1/0）或负数的比例被视为有效， 因此如果你想排除这些值，应当检查 返回的值。

未定义的值可以用 "0:0" 字符串表示。

自定义声道布局可以指定为一系列项，各项之间用 ’+’ 分隔。 每一项可以是：

  • 单个声道的名称（例如 ‘FL’、‘FR’、‘FC’、‘LFE’ 等）， 每项后面可选择在 ’@’ 之后附带一个自定义名称，（例如 ‘FL@Left’、 ‘FR@Right’、‘FC@Center’、‘LFE@Low_Frequency’ 等）

标准声道布局可以通过以下方式指定：

  • 单个声道的名称（例如 ‘FL’、‘FR’、‘FC’、‘LFE’ 等）
  • 标准声道布局的名称（例如 ‘mono’、 ‘stereo’、‘4.0’、‘quad’、‘5.0’ 等）
  • 以十进制表示的声道数量，后接 ’c’，得到该声道数量对应的默认声道 布局（参见函数 av_channel_layout_default）。注意并非所有声道数量都有 默认布局。
  • 以十进制表示的声道数量，后接 ’C’，得到具有指定声道数量的未知声道 布局。注意并非所有声道布局 描述字符串都支持未知声道布局。
  • 声道布局掩码，即十六进制表示、以 "0x" 开头的数（参见 libavutil/channel_layout.h 中的 AV_CH_* 宏）。

在 libavutil 版本 53 之前，用于指定声道数量的尾随字符 "c" 是可选的，但现在它是必需的；而声道布局掩码 也可以指定为十进制数（当且仅当后面不跟 "c" 或 "C" 时）。

另请参见 av_channel_layout_from_string 函数，它定义在 libavutil/channel_layout.h 中。

3 表达式求值# TOC

在求算术表达式时，FFmpeg 使用一个内部 公式求值器，它通过 libavutil/eval.h 接口实现。

一个表达式可以包含一元运算符、二元运算符、常量和 函数。

两个表达式 expr1 和 expr2 可以组合成 另一个表达式 "expr1;expr2"。 expr1 和 expr2 会依次求值，新 表达式的值即为 expr2 的值。

可用的二元运算符如下：+、-、 *、/、^。

可用的一元运算符如下：+、-。

一些内部变量可用于保存和读取中间 结果。可以使用 ld 和 st 函数访问它们，这两个函数带有一个从 0 到 9 变化的索引参数，用于指定 要访问的内部变量。

可用的函数如下：

abs(x)

计算 x 的绝对值。

acos(x)

计算 x 的反余弦。

asin(x)

计算 x 的反正弦。

atan(x)

计算 x 的反正切。

atan2(y, x)

计算 y/x 的反正切主值。

between(x, min, max)

如果 x 大于或等于 min 且小于或 等于 max，则返回 1，否则返回 0。

bitand(x, y)
bitor(x, y)

对 x 和 y 执行按位与/或运算。

在执行按位运算之前，x 和 y 的求值结果会被转换为 整数。

注意，转换为整数和再转换回 浮点数都可能损失精度。对于大数（通常是 2^53 及以上） 要警惕意外结果。

ceil(expr)

将表达式 expr 的值向上取整到最接近的 整数。例如，"ceil(1.5)" 为 "2.0"。

clip(x, min, max)

返回 x 被截断在 min 与 max 之间的值。

cos(x)

计算 x 的余弦。

cosh(x)

计算 x 的双曲余弦。

eq(x, y)

如果 x 与 y 相等，则返回 1，否则返回 0。

exp(x)

计算 x 的指数（以 e 为底，即欧拉数）。

floor(expr)

将表达式 expr 的值向下取整到最接近的 整数。例如，"floor(-1.5)" 为 "-2.0"。

gauss(x)

计算 x 的高斯函数，相当于 exp(-x*x/2) / sqrt(2*PI)。

gcd(x, y)

返回 x 和 y 的最大公约数。如果 x 和 y 都为 0，或者其中任一为负数或两者皆为负数，则行为未定义。

gt(x, y)

如果 x 大于 y，则返回 1，否则返回 0。

gte(x, y)

如果 x 大于或等于 y，则返回 1，否则返回 0。

hypot(x, y)

该函数与同名的 C 函数类似；它返回 "sqrt(x*x + y*y)"，即两条直角边长分别为 x 和 y 的直角三角形的斜边长，或者点 (x, y) 到原点的距离。

if(x, y)

对 x 求值，如果结果非零则返回对 y 求值的结果，否则返回 0。

if(x, y, z)

对 x 求值，如果结果非零则返回 y 的求值 结果，否则返回 z 的求值结果。

ifnot(x, y)

对 x 求值，如果结果为零则返回对 y 求值的结果，否则返回 0。

ifnot(x, y, z)

对 x 求值，如果结果为零则返回 y 的求值 结果，否则返回 z 的求值结果。

isinf(x)

如果 x 为 +/-INFINITY，则返回 1.0，否则返回 0.0。

isnan(x)

如果 x 为 NAN，则返回 1.0，否则返回 0.0。

ld(idx)

加载索引为 idx 的内部变量的值，该变量此前 已通过 st(idx, expr) 保存。 该函数返回所加载的值。

lerp(x, y, z)

返回在 x 与 y 之间按 z 的比例进行线性插值的结果。

log(x)

计算 x 的自然对数。

lt(x, y)

如果 x 小于 y，则返回 1，否则返回 0。

lte(x, y)

如果 x 小于或等于 y，则返回 1，否则返回 0。

max(x, y)

返回 x 与 y 中的最大值。

min(x, y)

返回 x 与 y 中的最小值。

mod(x, y)

计算 x 除以 y 的余数。

not(expr)

如果 expr 为零，则返回 1.0，否则返回 0.0。

pow(x, y)

计算 x 的 y 次幂，它等价于 "(x)^(y)"。

print(t)
print(t, l)

以日志级别 l 打印表达式 t 的值。如果未指定 l， 则使用默认日志级别。 返回所打印表达式的值。

random(idx)

返回一个介于 0.0 与 1.0 之间的伪随机值。idx 是 用于保存种子/状态的内部变量的索引，该值此前 可以通过 st(idx) 保存。

要初始化种子，需要把种子值作为 64 位 无符号整数保存到索引为 idx 的内部变量中。

例如，把值为 42 的种子保存到索引为 0 的内部 变量中，并打印若干个随机值： 

st(0,42); print(random(0)); print(random(0)); print(random(0))
randomi(idx, min, max)

返回一个介于 min 与 max 之间的伪随机值。idx 是用于 保存种子/状态的内部变量的索引，该值此前可以通过 st(idx) 保存。

要初始化种子，需要把种子值作为 64 位 无符号整数保存到索引为 idx 的内部变量中。

root(expr, max)

在区间 0..max 中找出一个输入值，使得以 expr 表示、以 ld(0) 为自变量的函数的值为 0。

expr 中的表达式必须表示连续函数，否则 结果未定义。

ld(0) 用于表示函数输入值，这意味着 给定表达式会以各种不同的输入值被多次求值， 表达式可以通过 ld(0) 访问该输入值。当表达式的求值结果为 0 时，就会返回相应的输入值。

round(expr)

将表达式 expr 的值四舍五入到最接近的整数。例如， "round(1.5)" 为 "2.0"。

sgn(x)

计算 x 的符号。

sin(x)

计算 x 的正弦。

sinh(x)

计算 x 的双曲正弦。

sqrt(expr)

计算 expr 的平方根。它等价于 "(expr)^.5"。

squish(x)

计算表达式 1/(1 + exp(4*x))。

st(idx, expr)

把表达式 expr 的值保存到一个内部 变量中。idx 指定存放该值的变量索引， 其取值范围为 0 到 9。该函数返回 保存在该内部变量中的值。

保存的值可以通过 ld(var) 取回。

注意：目前变量不在各个表达式之间共享。

tan(x)

计算 x 的正切。

tanh(x)

计算 x 的双曲正切。

taylor(expr, x)
taylor(expr, x, idx)

在 x 处求泰勒级数，给定一个表示 函数在 0 处第 ld(idx) 阶导数的表达式。

当级数不收敛时，结果未定义。

ld(idx) 用于表示 expr 中的导数阶数， 这意味着会对给定的表达式进行多次求值， 并在每次求值时使用不同的输入值，表达式可通过 ld(idx) 访问这些值。如果未指定 idx，则假定为 0。

注意，如果你拥有的是在 y 处而非 0 处的导数， 可以使用 taylor(expr, x-y)。

time(0)

返回当前的（挂钟）时间，单位为秒。

trunc(expr)

将表达式 expr 的值向零方向舍入到最接近的 整数。例如，"trunc(-1.5)" 为 "-1.0"。

while(cond, expr)

当表达式 cond 非零时对表达式 expr 求值， 并返回最后一次对 expr 求值所得的值，如果 cond 始终为假则返回 NAN。

以下常量可用：

PI

单位圆的面积，约为 3.14

E

exp(1)（欧拉数），约为 2.718

PHI

黄金比例 (1+sqrt(5))/2，约为 1.618

假设一个表达式在取值非零时被视为 "真"， 那么请注意：

* 的作用类似于 AND

+ 的作用类似于 OR

例如以下结构： 

if (A AND B) then C

等价于： 

if(A*B, C)

在你的 C 代码中，你可以扩展一元和二元函数的列表， 并定义可识别的常量，使它们可供你的 表达式使用。
